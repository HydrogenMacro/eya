# Bundled terminal fonts

These static WOFF2 files are Nerd Font Mono regular faces, subsetted for Latin text, common symbols, and Nerd Font private-use glyphs. The generator embeds the selected face in the standalone client. The source fonts are distributed under SIL Open Font License 1.1; the Nerd Fonts patcher is distributed under MIT. License texts are in this directory.

The files were downloaded from the official Nerd Fonts release packages and converted from their regular Nerd Font Mono TTF faces to WOFF2. Source font family names and licensing metadata are retained; CSS uses Eya-prefixed aliases. These local files are fixed snapshots and are updated when the bundled assets are deliberately refreshed.
